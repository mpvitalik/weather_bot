# 🌧 Telegram Rain Alert Bot (Бот оповещения о дожде)

Telegram-бот, который отслеживает погоду в городах пользователей и присылает предупреждение **за 30 минут до начала дождя**, чтобы вы не забыли взять зонт.

---

## ✨ Возможности

1. **Бесконечное количество подписчиков:**
   - Данные пользователей и настройки хранятся в асинхронной базе данных SQLite (с режимом WAL для высокой производительности).
   - Запросы к погодным сервисам оптимизированы: пользователи из одного города/района группируются, чтобы не превышать лимиты API.

2. **Выбор города:**
   - Поиск по названию (на русском или любом другом языке).
   - Определение по GPS-геопозиции (кнопка в чате).
   - Разрешение неоднозначностей (если городов с таким названием несколько — выдается выбор кнопками).

3. **Высокоточное прогнозирование осадков (за ~30 минут):**
   - Анализ радара осадков с 15-минутным шагом прогнозирования (WMO коды + миллиметры осадков).
   - Определение интенсивности: морось, небольшой дождь, ливень, гроза, мокрый снег.
   - Защита от спама (cooldown): после отправки предупреждения бот не будет повторять уведомления каждые 5 минут во время одного и того же дождя.

4. **Текущая погода по запросу:**
   - Температура и «ощущается как».
   - Влажность, атмосферное давление (в мм рт. ст.), скорость ветра, облачность.
   - Статус осадков на ближайший час.

5. **Гибкие настройки:**
   - Включение / выключение уведомлений в один клик.
   - Настройка времени предупреждения (15, 30, 45 или 60 минут).

## 🚀 Установка и запуск

### 1. Получение токена Telegram-бота
1. Откройте в Telegram бота [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot` и следуйте инструкциям (задайте имя и username).
3. Скопируйте полученный **API токен** (например, `123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ`).

### 2. Настройка окружения
В файле `.env` укажите ваш полученный токен:

```ini
BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN_HERE
OPENWEATHER_API_KEY=YOUR_OPENWEATHER_API_KEY_HERE
```

### 3. Запуск бота

```bash
# Активация виртуального окружения
source venv/bin/activate

# Запуск бота
python3 main.py
```
